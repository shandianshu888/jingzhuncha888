隐私政策

机场精准查（以下简称“本站”）深知数字隐私对网络用户的重要性。我们承诺遵循极简与透明原则：不采集个人身份敏感数据，更绝不触碰任何网络代理凭证。

核心隐私原则

CORE PRINCIPLES
01

绝不收集凭证

本站绝不要求、不接收且无权收集用户的代理节点订阅链接、账号密码、服务器配置或个人网络通信明文。

02

本地计算与隔离

在“机场对比”工具中您所输入的测速记录、中位数与备注，完全存储于您当前浏览器的 LocalStorage 中，不会上传到任何服务器。

03

透明外链披露

本站部分服务商跳转链接包含推广标识。点击跳转后将进入第三方服务商网站，由其独立的隐私政策提供规范保障。

详细条款与合规声明

一、我们收集哪些信息？

作为纯静态架构的知识与测评站点，我们仅在基础设施层面记录标准、匿名的 Web 访问日志（如访问时间、请求页面 URL、客户端浏览器类型及匿名化 IP 地址）。此类日志仅用于保障网站运行安全、防护恶意爬虫与分布式拒绝服务攻击，不与任何个人真实身份相关联。

二、关于浏览器本地存储（Local Storage）

为了提升用户体验，我们在您的设备本地使用 LocalStorage：

  • 对比测速工具记录：您手动录入的各机场时延与丢包率数据完全保留在您本地设备上。清除浏览器缓存即可彻底抹除。
  • 搜索历史与主题偏好：仅用于在本地快速匹配历史搜索词，无跨站追踪行为。

三、第三方服务与外部链接

本站托管于全球高速 CDN 节点，并通过 GitHub / Cloudflare 进行安全分发。本站页面包含指向第三方机场服务商、客户端软件官方发布页（如 Apple App Store、GitHub Releases）的超链接。我们强烈建议您在离开本站后，查阅相应第三方平台的隐私政策，我们不对第三方站点的隐私实践承担法律责任。

四、未成年人保护

本站内容主要面向网络工程师、外贸从业人员、科研学者及成年网络用户。若您未满 18 周岁，请在监护人指导下阅读本站内容。

五、政策变更与联系方式

本隐私政策可能随法律法规或网站功能迭代而不定期更新。重大变更将在本页面显著位置公示。如对本政策有任何疑问或建议，可通过官方 Telegram 频道（@Ace668811）与编辑团队取得联系。
