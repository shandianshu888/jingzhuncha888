QUICK START

五步完成首次连接

  1. 01选择并安装客户端

    iOS 使用小火箭；桌面系统可使用 Clash Party。

  2. 02复制订阅链接

    登录机场网站，在仪表盘或订阅页面复制专属链接，不要公开分享。

  3. 03导入订阅

    在客户端选择“从 URL 导入”，粘贴链接后更新配置。

  4. 04选择节点

    先选距离较近的香港、日本或新加坡节点，再根据实际表现切换。

  5. 05开启代理

    允许系统 VPN 或代理权限，打开常用网页确认连接是否生效。

TROUBLESHOOT

连接不上，按顺序检查

大部分故障来自订阅失效、配置未更新或节点临时不可用，不需要立即卸载重装。

订阅导入失败

确认复制的是完整订阅链接；重新登录机场后台刷新链接；检查套餐是否到期或流量是否用尽。

节点全部超时

先更新订阅，再切换网络和节点；关闭其他 VPN 或代理软件；确认设备系统时间准确。

已连接但网页打不开

检查系统代理是否开启，尝试切换规则模式与全局模式；更换 DNS 或退出客户端后重新启动。

晚高峰速度下降

切换同地区的其他节点，或改用临近地区节点。可在机场对比页记录不同时段测速结果。

SECURITY

安装与订阅安全

  • 不要在群聊、论坛或截图中公开完整订阅链接。
  • 客户端只从 App Store 或官方 GitHub Releases 下载。
  • 遇到系统安全提示时，先核对开发者与文件来源，不要盲目关闭安全软件。
  • 订阅泄露后应立即在机场后台重置订阅链接。
